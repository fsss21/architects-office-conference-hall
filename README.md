# Конференц-зал

## Краткое описание ПО

Интерактивный киоск конференц-зала музея «Уткина дача». Рассказывает об истории музейного комплекса, научной деятельности и образовательных программах. Есть каталог материалов и разделы с видеокарточками (лекции, экскурсии, мастер-классы).

## Сценарий работы ПО

### Стартовый экран

Заставки нет — сразу главное меню. В шапке — название временной выставки/конференции. Карусель из трёх тем:

- История создания музейного комплекса
- Научная деятельность
- Образовательные программы

Кнопки:

- **Подробнее** — экран темы (SubMenu)
- **Перейти в каталог** — каталог
- **Назад** — без перехода внутри приложения

### Экран темы (SubMenu)

**История создания музейного комплекса** — текст и фото.

**Научная деятельность** — слева подразделы:

- Исследования
- Публикации
- Конференция

**Образовательные программы** — подразделы:

- Лекции
- Экскурсии
- Мастер-классы

При выборе подраздела с видео открывается сетка карточек (Лекция 1…, Экскурсия 1… и т.д.) с постраничной навигацией.

На экране темы и в каталоге доступны фильтры и поиск в шапке.  
**Назад** — на главное меню или на уровень выше внутри подраздела.  
**Перейти в каталог** → каталог.

### Каталог и карточка объекта

Документы и материалы; карточка с навигацией стрелками. **Назад** → главное меню.
